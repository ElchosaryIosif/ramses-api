# Ramses Bazaar Database Schema

Gift-shop catalogue and orders. Postgres; migrations in
`src/main/resources/db/migration` (Flyway), validated by Hibernate on start-up.

**Conventions**

- `snake_case` column names, `timestamptz` timestamps stored in UTC
- `text` without length caps (Greek content); lengths are enforced in the services
- Single-row tables (`catalogue`, `shop_settings`) use `id = 1`, enforced by a `CHECK`

---

## catalogue

The catalogue's revision. Every save of the product list must name the revision
it was edited from; a stale one is answered with 409 and the current catalogue.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| id | smallint | NOT NULL | — | PK, always 1 |
| rev | integer | NOT NULL | 0 | Bumped on every save |
| updated_at | timestamptz | NOT NULL | now() | |

## product

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| id | text | NOT NULL | — | PK, generated by the admin panel (`[a-zA-Z0-9_-]{4,40}`) |
| position | integer | NOT NULL | — | Display order |
| name | text | NOT NULL | — | |
| category | text | NOT NULL | — | `jewelry`, `clothes`, `home`, `incense`, `collectibles` |
| price | numeric(10,2) | NOT NULL | — | Euros, `>= 0` |
| tag | text | NOT NULL | `''` | `''`, `new`, `best`, `sale` |
| description | text | NOT NULL | `''` | |
| in_stock | boolean | NOT NULL | true | |
| image | text | NULL | — | `/api/images/<key>` or an `https://` URL |
| created_at | bigint | NOT NULL | — | Epoch milliseconds, as the shop front uses it |

## product_image

Product photos, addressed by the first 40 hex characters of their SHA-256.
Photos no product references are deleted on the next catalogue save.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| image_key | text | NOT NULL | — | PK |
| content_type | text | NOT NULL | — | `image/jpeg`, `png`, `webp` or `gif` |
| data | bytea | NOT NULL | — | At most 4 MB |
| created_at | timestamptz | NOT NULL | now() | |

## shop_settings

Public contact and bank-transfer details, and the admin password.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| id | smallint | NOT NULL | — | PK, always 1 |
| whatsapp, phone, address, iban, bank, account_name, email | text | NULL | — | Public |
| password_hash | text | NULL | — | bcrypt; set on first start-up |
| password_version | integer | NOT NULL | 0 | Carried in session tokens; bumping it signs everyone out |

## shop_order

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| id | uuid | NOT NULL | gen_random_uuid() | PK |
| customer_name, customer_phone, customer_email, customer_address | text | NOT NULL | — | |
| notes | text | NOT NULL | `''` | |
| subtotal, shipping, total | numeric(10,2) | NOT NULL | — | Computed from catalogue prices |
| status | text | NOT NULL | `NEW` | `NEW`, `CONFIRMED`, `SHIPPED`, `CANCELLED` |
| created_at, updated_at | timestamptz | NOT NULL | now() | |

- **Index:** `created_at DESC`
- **Relations:** 1:N with `order_item`

## order_item

A snapshot of the product at order time, so later catalogue edits don't change past orders.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| id | uuid | NOT NULL | gen_random_uuid() | PK |
| order_id | uuid | NOT NULL | — | FK → `shop_order`, `ON DELETE CASCADE` |
| position | integer | NOT NULL | — | |
| product_id | text | NOT NULL | — | Not a FK: the product may be deleted later |
| product_name | text | NOT NULL | — | |
| unit_price | numeric(10,2) | NOT NULL | — | |
| quantity | integer | NOT NULL | — | `> 0` |
